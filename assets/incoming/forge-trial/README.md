# 完整静态火炉试跑

第一版直接使用两张完整火炉图，运行时根据状态切换纹理，不再拆分炉体和炉火，也不制作动画。

请将模型原图放在本目录：

- `forge-with-fire.png`：有火的完整火炉；
- `forge-without-fire.png`：无火的完整火炉。

两张图必须使用相同画布、相同镜头、相同火炉位置和相同主体比例。物件放在画面中央，背景可使用统一纯绿色或透明；处理时可以直接提取中央火炉，不要求保留整张背景。水印不作为本批处理的阻塞条件，只要不落入中央物件提取区域即可。

不要生成独立炉火层、3×2 图集、逐帧动画、第二个火炉、文字或 UI。

建议尺寸：原图 `1920×1080` 或 `2048×1152`；运行时再按统一锚点做最近邻缩放。
