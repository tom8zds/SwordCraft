# 铸剑录

横屏优先的 PixiJS 网页锻造游戏。每天获得三把普通铁剑，通过炭炉、工作台、墙面单排挂剑区和上供台经营铁匠铺，在随机锤击风险中提高武器价值并满足逐日增长的上供要求。

## 运行

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

主游戏打开 `/`；`/art-preview.html` 是独立的历史美术/镜头验收页，不读写游戏存档。

主入口现已采用已确认的正交砖房、接顶炭炉、单排墙钩，以及模型生成的大锤和基础铁剑。所有场景物件随镜头整体横移，HUD 固定。锤头空槽内的五色概率圆环由真实权重动态绘制，不是烘焙图片；剑上工作台后显示详情。

场景纹理位于 `public/assets/game/smithy/`，73 件独立武器位于 `public/assets/game/weapons/`，遗物、家具、道具及面板位于 `public/assets/game/furnishings/`。从保留原图重新导出不会额外调用付费生成：

```bash
node scripts/prepare-smithy-assets.mjs
node scripts/process-mythic-weapons.mjs
node scripts/verify-mythic-weapons.mjs
node scripts/process-furnishing-assets.mjs
```

素材生成（火山引擎 Seedream 5.0 Pro）：

```bash
export VOLCENGINE_ARK_API_KEY='你的火山引擎 API Key'
npm run assets:generate:seedream -- --dry-run
npm run assets:generate:seedream -- --out-dir output/seedream/batch-01
```

后续付费生图硬上限为 **2,610,000 像素/张**；默认竖图 `1344x1792`、横图 `1920x1080`，三件批次 `2400x1080`。请求前校验明确宽高，不接受 `2K`、`4K`、`auto`；旧付费原图保留，规范化与验证不发起生成请求。

提示词批次和图层拆分说明见 [`docs/assets/ASSET-PROMPTS.md`](docs/assets/ASSET-PROMPTS.md) 与 [`docs/assets/SEEDREAM-API.md`](docs/assets/SEEDREAM-API.md)。

## 炭炉与单排挂剑墙样片

运行 `npm run dev` 后打开 `/art-preview.html`，可单独检查新美术，不修改游戏存档。生产构建也包含这个入口。

- 正面正交砖房：无木梁、木柱、木地板或消失点；左侧锻造炭炉的烟道连接天花板。
- 右侧只有一排墙面金属挂钩，房间向右延伸。拖动场景空白处、触屏横滑或滚轮会平移整个世界：砖墙、地面、炭炉、工作台、挂钩和剑一起移动，页面 HUD 固定。取剑拖动不触发镜头，镜头到左右边界停止。
- 可关闭示意剑，只检查挂钩资产；预览剑复用完整独立武器目录中的真实基础铁剑贴图。
- 模型原图、图层和请求参数：`assets/incoming/seedream-charcoal-single-row-20261019/`。
- 同坐标图层、重组图和清单：`assets/processed/seedream-charcoal-single-row-20261019/`。
- 运行时预览贴图：`public/assets/art-preview/charcoal-single-row/`。

## 操作

- 将剑拖入火炉：永久完成加热。
- 将已加热的剑拖上工作台：点击或按住锤子，最高每秒两次；动作依次右上蓄力、左下挥击、命中短停、右抽与复位，火花在锤面接触台心时爆出。
- 将剑拖回墙面挂钩：保存并稍后继续锻造。拖动空白区域、横向滑动或滚轮浏览整个房间；不是挂剑区单独滚动。
- 将剑拖到上供台：敲上供铃交付；台旁牌子显示当天需求金额和当前武器价值。价值不足或台上无剑时，三秒内第二次敲铃确认扣 1 血过日；其他武器不会自动消失。
- 火炉左侧四层柜：上两层首格为遗物祭台，其余位置陈列已持有遗物；第三层留空，第四层分别放武器图鉴、遗物图鉴、操作手册。点击书本直达对应栏目，商人入口位于柜子左侧。
- 武器图鉴展示 73 件独立横向实像与每件不超过 50 字的描述；遗物图鉴展示 15 件真实素材小格。未解锁保留真实外观、以 20% 透明度区分，书页和交易使用自绘滚动条。
- HUD 左上生命、正中神历日期、右上金币和当前武器总数。点击日期打开完整月份日历，可切换月份；第 1 日从神历 26 年 3 月 5 日开始。商人每四个游戏日到访，日历标记已知达标情况与商人日。
- 工作台下方放龙鳞、沙漏与数量：拖到砧台装备龙鳞或撤销最近一锤；装备鳞片可在敲打前拖回工作台下方，不再放进柜子。
- 商人每四日补货，普通铁剑、龙鳞、沙漏每次各独立随机 3～5 件，可重复购买至售罄；三种特殊基础武器各 1 件。商品拖到结算垫后鸣铃成交，打开面板或刷新网页不重抽库存。普通铁剑拖入祭槽后敲小钟换遗物，成交前不扣款或消耗祭品。
- 键盘后备：Tab/Enter 选剑，`F/A/R/T` 移到炭炉/工作台/墙钩/上供台，`Space` 敲锤，左右方向键浏览房间，`B` 打开书本，`C` 打开日历，`Escape` 关闭面板。

进度自动保存到浏览器 `localStorage`。竖屏设备会提示旋转到横屏。

## 等级概率与锻造补偿

基础权重由当前等级 L（可达上限为单手剑 100、其他路线 99）决定：破坏 `min(4, L×0.25)`，损伤 `min(12, 8+L×0.25)`，维持 `42`，大成功 `5`，成功补足总权重 `100`。无遗物、无补偿时：

| 当前等级 | 破坏 | 损伤 | 维持 | 成功 | 大成功 |
|---|---:|---:|---:|---:|---:|
| 0 | 0% | 8% | 42% | 45% | 5% |
| 1 | 0.25% | 8.25% | 42% | 44.5% | 5% |
| 16～100 | 4% | 12% | 42% | 37% | 5% |

- 先计算等级基础权重并应用遗物，再计算每把剑的锻造补偿，最后应用下一锤大成功强化（大成功权重 +25），统一归一化。0 级的破坏权重始终为 0，遗物也不能增加。
- 每次维持或损伤后，该剑的 `forgeRelief` 增加 1 层，最高 5 层；每层将破坏权重降低 0.5、损伤降低 2（各最低为 0），实际减少的权重全部转给成功，不改变维持与大成功。损伤后用降低的当前等级和新层数计算下一锤。
- 成功或大成功清空补偿；破坏或被阻挡的破坏不改变层数。存放、移动与换日保留，不能跨剑共享。沙漏恢复锤前补偿层数，不回退 RNG。新剑和缺少该字段的旧存档从 0 层开始。
- 工作台显示补偿层数与 0 级不会破坏提示；下一锤概率只在锤头真实圆环表达，顶部 HUD 不再显示概率图例。


## 已实现内容

- 五种锤击结果、登神充能与限时防破坏状态。
- 龙鳞、沙漏及 15 件独立遗物。
- 单手剑 100 级最终形态“无尽之剑”，其他路线最高 99 级；首次达到 9 级的普通铁剑仍等概率随机成为单手剑、双手剑或剑盾，不弹选择框。降级保留已获得外形，沙漏回到最终进化之前可恢复原形。
- 每日交付、生命、金币、商人、里程碑和无尽日期。
- `BigInt` 经济数值、可恢复的确定性随机状态和版本化存档。
- 白/绿/蓝/紫/金/红品质铭牌；登神渐金、相对当前形态放大 1.2 倍并抖动，到期恢复并散出金色粒子。减少动态效果时关闭抖动，不改锻造判定。

本轮生产构建与 10 个文件共 132 项行为测试通过。已实际运行分段曲线与命中火花、真实长按四连锤、登神 1.2 倍与到期复原、100 级无尽之剑与沙漏还原、73 件描述/实像图鉴、工作台下方道具拖放、左侧商人门以及普通剑/龙鳞/沙漏连续购买与读档库存；桌面和手机横屏均做针对性冒烟。素材技术报告与来源位于 `assets/processed/mythic-weapons-20261020/`，不重复旧版全部 72 件的复杂逐图锤击。

视觉范围：73 件武器一一对应独立贴图；40 级后从 45 级开始的六系 42 件形态重做，越后期越大、繁复、绚丽，剑盾高阶为骑士长枪配宝石法阵门盾，另新增参考指定造型的无尽之剑。本轮实际 15 张 2400×1080 原图，首张仅最终形态、后 14 张各取三件，未追加付费重试。误生部件用可追溯真实栅格修复，低阶 30 件和设施道具 30 件复用。第三方造型参考不宣称原创或商业授权；炭炉仍为静态贴图。
