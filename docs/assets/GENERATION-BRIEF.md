# 英雄资产生成说明

生图平台会自动优化提示词，因此本项目使用中文自然语言提示词。首批可直接复制的完整提示词在 [`ASSET-PROMPTS.md`](./ASSET-PROMPTS.md)。

## 当前第一版：完整静态火炉

请直接使用 [`ASSET-PROMPTS.md`](./ASSET-PROMPTS.md) 的最新炭炉描述与 `seedream-brick-room.json` 的统一场景约束。火炉必须是抬高拱口、厚石炉台、红热炭床、下方镂空拱座并连接天花板的锻造炭炉，采用固定正面正交投影，不是木柴壁炉。先确认统一场景，再提取与场景同坐标的炭炉和烟道；后续无火图只熄灭炭床与局部光照，不移动任何结构。第一批示例不制作火焰图集或动画。

## 后续资产角度原则

- 炭炉、墙面单排金属挂钩、提交台、遗物祭台：只生成游戏镜头看到的固定正面正交视图，不生成多排木架或无用途转面。
- 锤子：第一版只生成静止姿态；不生成锤击动画关键帧，不生成完整转面。
- 剑：生成一个统一主视角，墙面悬挂时剑尖向下、护手落在双挂钩上；工作台和拖拽时的旋转由 PixiJS 完成。
- 商人或铁匠手臂：第一版先使用程序化占位，不生成无用途的人物转面。
- 动画资产：第一版暂不制作。后续如果恢复动画，再单独确定网格、帧尺寸、锚点和帧顺序。

## 收图要求

- 使用模型原始输出，不提前抠图、切片、缩放、锐化或重新压缩。
- 背景优先透明；不可靠时用统一纯色背景。
- 无文字、编号、边框、UI 或水印。使用 Seedream API 时显式设置 `watermark:false`，原始生成图不通过裁切掩盖水印。
- 同一资产族保持相同像素密度、光源、视角和比例。
- 生成记录写入 `assets/incoming/<batch>/batch.txt`，格式见 `assets/incoming/README.md`。原图保留，运行时稿再单独处理。

## 验收

开发代理收到图片后负责：尺寸、alpha、色数、像素簇、中央提取范围、锚点和游戏内合成检查。模型输出只有在游戏内通过后才进入 `assets/approved`。
