# 完整静态火炉提示词

第一版火炉不拆分炉体和炉火，也不制作动画。请生成两张完整、独立、可直接切换的静态图片：

- `forge-with-fire.png`
- `forge-without-fire.png`

两张图保持同一正面正交镜头、画布、位置、比例和轮廓，只改变红热炭床、少量短焰与相邻反光。炭炉烟道接入砖房天花板；优先从统一场景提取，不能把带顶盖的独立矮烟囱拼进房间。Seedream 请求必须使用 `watermark:false`。

## 有火图

> 固定正面正交的高细节像素锻造炭炉：厚石砌圆肩炉身、腰高小拱形炉口、前伸厚炉台、下方镂空拱座、竖直烟道接实天花板。灰浆、崩角、裂纹、烟熏、铁箍和铆钉清楚。炉口内是黑炭、焦炭、橙红热裂纹与少量短焰，不是大束木柴和取暖壁炉。保持统一场景中的比例、原坐标和炉火光向；砖石暗部使用弱中性补光，无独立紫色边光或斜射光柱。不加人物、剑锤、第二个炉体、文字、UI、水印或动画图集。

## 无火图

> 以有火参考图为唯一结构基准，保持相同正面正交投影、全画布和全部坐标，仅熄灭红热炭床、短焰、余烬与邻近红光。保留黑炭、焦炭、灰烬、腰高拱口、厚炉台、镂空拱座和接顶烟道，石砖与铁件不改变。无火焰、红热、火星、烟或 Bloom；无文字、人物、UI、水印或图集。

## 生成后的检查

1. 两张图叠加对齐时，砖块、铁件、火钳、灰门和阴影的位置必须完全一致。
2. 中央火炉物件应有清晰完整轮廓，不能被边缘裁切。
3. 有火图只在抬高拱口内显示红热炭床与短焰；无火图不能残留火星、热裂纹或红光。
4. 运行时只需在两个静态纹理之间切换，不需要动画时间轴或火焰图集。
