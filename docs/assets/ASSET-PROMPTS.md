# 《铸剑录》首批素材提示词

这份文档提供可直接使用的中文素材描述。当前示例以 `seedream-brick-room.json` 与 `art-direction.md` 的最新约束为准：正面正交砖房、接顶烟道锻造炭炉、唯一一排可横向滚动的墙面挂钩。火炉静态状态优先确认，不恢复已否决的三层木架、木质建筑或三分之四透视。

## 统一锁定词

除特别说明外，每条提示词都默认加入以下要求：

> 高细节 HD-2D 手工像素画，固定正面正交立面，无消失点、远近缩放或斜侧墙。房屋为砖顶、砖墙和石地基；只允许工作台等家具使用木材。左侧红热炭床是主暖光，弱中性环境光保证暗部可读，禁止独立蓝紫轮廓光和大面积斜射光柱。像素簇、材质和光源统一，不画照片、平滑 3D、UI、文字、水印或无用途转面。

场景以 `640×360` 像素审美为基准，用 `1920×1080` 输出无水印候选。优先在同一完整场景内确认比例和光影，再调用图层拆分，按响应边界还原到同尺寸透明画布；不能靠独立裁剪和缩放猜测设施位置。原图、提示词、参考图哈希和图层坐标分别保留。

## 1. 完整火炉：两张静态图

两张图必须使用完全相同的镜头、画布、物件位置、尺寸和轮廓，只改变炉膛状态。不要生成炉火图层、图集或动画帧。

### 1.1 有火

> 生成固定正面正交的锻造炭炉，不是取暖壁炉。厚石砌圆肩炉身，腰高小拱炉口、前伸厚炉台和下方镂空拱座，竖直烟道连续接入天花板。黑炭、焦炭和红热裂纹清楚，少量短焰只在炉口内，不能是木柴篝火。石砖灰浆、崩角、煤灰与铁件可读，炭床暖光只影响相邻受光面。保持完整场景中的原尺寸、坐标、镜头和材质，不加人物、剑锤、文字或 UI。

### 1.2 无火

> 在有火参考图的完全相同坐标与画布上，只熄灭炭床、短焰、余烬与局部红热反光；保留冷却炭块、灰烬、石砌炉身、小拱口、厚炉台、镂空拱座和接顶烟道，砖块与工具不得移动或重画。保持正面正交视图，无人物、文字、UI 或水印。

建议文件名：

```text
forge-with-fire.png
forge-without-fire.png
```

## 2. 铁匠铺背景

> 生成固定正面正交的砖砌铁匠铺背景：砖顶带、灰浆接缝、裂纹砖墙和石地基，没有木梁、木柱、木屋顶或木地板。没有消失点、侧墙或向远处收缩的地板。左侧预留接顶炭炉、中部预留工作台、右侧预留单排墙面挂剑带，仅画连续墙地材质及合理环境光，不画任何火炉、烟道、桌子、铁砧、挂钩、架子、剑锤、人物、文字或 UI。

## 3. 工作台与铁砧

> 生成固定正面正交的厚木工作台与一个铁砧，作为家具而非房屋结构。台面、粗木腿、横撑、铆钉、刀痕、磨损木纹和铁屑可读；铁砧具有空锻打面、砧角、凹痕、冷钢高光和暗面。保持共同场景的原比例、同一地面基线和炉火受光方向，不画透视房间、剑、锤子或人物手臂，不生成文字和 UI。

## 4. 大型锻造锤

> 生成一把独立的大型双手锻造锤 HD-2D 像素资产，锤子竖向居中，锤头明显大于普通工具锤。锤头由厚重外轮廓、锻打面、侧面斜切、冷金属高光、氧化暗面、铆钉、箍带和划痕组成；深色硬木锤柄有缠带、金属尾帽、握持磨损和牢固的头柄连接。锤头侧面保留一个无遮挡的圆形凹槽，凹槽内部为空，不要绘制彩虹概率环，概率环将在 PixiJS 运行时按真实概率绘制。只生成一把锤子，保持完整轮廓，统一纯绿色或透明背景，不要手臂、铁砧、剑、文字或 UI。

## 5. 单排墙面挂钩

> 一排等间距金属双挂钩直接固定在砖墙上，所有钩子高度相同并随房间向右延伸；只允许这一排，不能出现第二排、木架、搁板、木背板或柜子。提取为透明图层时只保留金属钩和固定铆钉，不能携带砖墙底板。像素密度、正面正交视角和炉火受光与共同场景一致，钩位保持空置，剑由程序独立绘制。镜头横移时整个房间、砖墙、炭炉、工作台、钩和剑同步移动；不是仅挂钩滑动，HUD 固定。

## 6. 剑类资产

剑统一使用一个主视角，整把完整居中。墙面悬挂时剑尖向下、护手落在双挂钩上，握柄在钩位上方；工作台与拖拽旋转由 PixiJS 完成。每次只生成一把剑，不能生成转面图、图鉴网格或烘焙挂钩。

### 6.1 普通铁剑基础形

> 生成一把可信的普通铁剑 HD-2D 像素英雄资产。剑刃有刃尖、主刃、刃脊、血槽、刃口高光、锻造纹理和局部氧化暗面；护手是简单但结实的铁制结构，握柄有深色皮革缠带、柄首和连接铆钉。比例适合单手持握，轮廓清楚，保留后续进化空间。剑身略带低温金属光，不发光，不带魔法粒子。只生成一把完整普通铁剑。

### 6.2 普通铁剑：单手剑路线

> 以普通铁剑基础形为参考，生成一把高阶单手剑：细长灵活的剑身、轻量护手、银色翼状装饰、清晰铭文和精密铆接结构，剪影必须一眼看出是单手剑。材质从锻铁逐步过渡到精炼钢和银色高光，保留像素簇和锻造痕迹，不要盾牌、双手握柄或夸张魔法光效。

### 6.3 普通铁剑：双手剑路线

> 以普通铁剑基础形为参考，生成一把高阶双手巨剑：更宽更厚的剑身、更长的握柄、沉重护手和配重柄首，剪影强调重量和破坏力。刃面有层叠钢材、深色锻纹、缺口和冷光高亮，不要盾牌、短刃或轻盈细剑比例。

### 6.4 普通铁剑：剑盾路线

> 以普通铁剑基础形为参考，生成一把高阶防御型剑盾武器资产。剑身保持中等长度和坚固比例，护手更宽，增加护臂结构、护手挡片和小型盾牌连接件；整体剪影表现防守、守城和稳定，不要生成完整人物或独立大盾，不要变成长柄武器。

### 6.5 树枝：生命之树路线

> 生成一把从树枝成长而来的生命之树系武器。主体保留自然分叉、木纹、年轮、嫩芽、藤蔓和树脂高光，轮廓从短枝逐渐成长为带有根须与枝冠的木剑；木材中出现柔和的生命脉络和少量绿色能量，但不能变成塑料或纯绿色发光棒。保持剑状可读轮廓，不能生成整棵树、人物或森林背景。

### 6.6 铁钉：流星锤路线

> 生成一把从铁钉成长而来的流星锤系武器。主体强调锤头、金属链节、星核和摆锤结构，轮廓从粗短铁钉逐渐变为沉重链锤；金属表面有锻打纹、氧化暗面、星尘裂纹和少量冷蓝高光。必须是一件可读的独立武器，不要生成一整套武器、人物或宇宙背景。

### 6.7 匕首：刺客武器路线

> 生成一把从匕首成长而来的刺客系武器。主体强调短刃、双刃、不对称护手、毒液槽、黑色皮革和隐蔽的铆接结构，剪影敏捷、锋利、低重心；金属以冷灰、暗紫和少量深红反光为主，不要生成血迹、人物、披风或大面积烟雾。

## 7. 遗物图标

> 高细节 HD-2D 像素道具图标，硬边像素簇，清晰轮廓，少量受控 Bloom，只突出主体材质，不要文字、字母、数字、UI、边框、手指和场景背景。

## 8. 对话框、面板和按钮

UI 文字由网页 DOM 渲染，图像模型只生成没有文字的材质框、底板和图标。统一提示词：

> 高细节 HD-2D 像素游戏 UI 组件，像素边缘清晰，深棕木材、旧黄铜、羊皮纸和铁件材质统一，九宫格拉伸友好，四角和边缘完整，中心区域保持干净平整，不要任何文字、字母、数字、符号、图标、按钮标签或人物。

### 8.1 深色场景对话框

> 生成一块深色铁匠铺提示框底板：深棕木框、旧铁包边、四角铆钉、内部暗色羊皮纸和一点暖色边缘光；中心大面积留空，适合显示锤击结果、低价提交警告和操作提示。输出一张独立 UI 底板，透明或纯色背景。

### 8.2 书本面板

> 生成一本摊开的旧铁匠手记 UI 面板：左右两页厚羊皮纸、深木色书脊、金属护角、纸张折痕、空白页边和轻微墨迹纹理；页面主体必须保持空白，不能出现可读文字，适合 DOM 叠加记录、图鉴和操作手册。

### 8.3 商店与遗物卡片

> 生成一张可重复使用的像素商店卡片底板：深色木框、铜色内边框、顶部小型装饰槽、中间大面积空白展示区和底部价格/操作区域；无文字、无商品、无数字，适合显示商人物品或遗物图标。

### 8.4 金色确认按钮

> 生成一个横向像素确认按钮的空白底板：旧黄铜边框、深木色按钮面、中心留空、四角铆钉，提供正常、悬停、按下三种状态的视觉变化；不要生成按钮文字或图标，不要圆角玻璃质感。

### 8.5 危险与禁用按钮

> 生成两个同尺寸的空白像素按钮底板：一个是暗红铁锈色危险状态，一个是低对比灰棕色禁用状态；保留厚重边框和像素阴影，不要文字、数字、图标、渐变玻璃效果。

## 9. 通用负面提示词

可以作为所有生成任务的负面提示词追加：

```text
照片，写实 3D，平滑矢量，抗锯齿，模糊，低清放大，塑料材质，现代 UI，文字，汉字，英文，数字，logo，水印占据主体，边框，编号，多余物件，多把武器，人物全身，手指，转面图，四视图，角色立绘，背景透视漂移，镜头漂移，错误的火光方向，随机改变比例，过度 Bloom，整张图泛橙，裁切主体，缺失握柄，断裂轮廓
```

## 10. 输出与验收

1. 同一资产族先生成一张风格母图，再用母图作为后续参考。
2. 独立物件居中生成，优先保留原始大图；运行时素材再做抠图、最近邻缩放和锚点统一。
3. 火炉有火/无火必须像复制粘贴一样保持主体位置一致，只允许炉膛明暗和火焰状态不同。
4. 剑与遗物单件生成，不要生成图鉴网格；图鉴和商店布局由代码完成。
5. 最终验收同时看原图、缩小到目标尺寸的像素轮廓，以及放入 Pixi 场景后的实际识别度。
